# Projeto para Overleaf

Este diretório contém uma cópia portátil do artigo e os arquivos incluídos por
ele. O manuscrito de trabalho original permanece em
`documentacao/artigo_codesign/main.tex`.

## Importação

1. No Overleaf, escolha **New Project > Upload Project**.
2. Envie o arquivo `artigo_skills_overleaf.zip`.
3. Confirme `main.tex` como documento principal.
4. Se necessário, selecione **pdfLaTeX** em **Menu > Compiler**.

O arquivo `.latexmkrc` já solicita pdfLaTeX. O manuscrito usa a classe oficial
`elsarticle`, distribuída pelo TeX Live do Overleaf. O arquivo `highlights.txt`
deve ser enviado separadamente como Highlights durante a submissão.
