# Benchmark de uso realista — API Gérard web

**Estes números representam uso realista simulado (sessões com pausas de leitura/raciocínio entre passos), não a capacidade máxima teórica do servidor.** Não houve martelamento de requisições simultâneas em massa — o servidor guarda uma única situação ativa em memória por processo (não é multiusuário), então o cenário realista é sessões sequenciais, com só um número pequeno delas em paralelo representando poucos usuários simultâneos.

Base URL: `http://localhost:18099`  
Sessões sequenciais: 40  |  Sessões em paralelo: 3  |  Think-time simulado por pausa: 2000–8000 ms (uniforme)

Sessões com falha inesperada (fora do fluxo determinístico previsto): 3/40 sequenciais, 2/3 paralelas.

**Leitura diferente para cada bateria:** nas sessões *sequenciais*, qualquer falha aqui é bug real (do harness ou do servidor), já que só existe uma sessão de cada vez e o fluxo é determinístico. Nas sessões *em paralelo*, uma falha deste tipo normalmente significa outra coisa: duas sessões disputando a MESMA "tentativa de classificação" global do servidor ao mesmo tempo — uma responde a categoria enquanto a outra ainda está no meio do próprio fluxo, e a sequência de uma corrompe a da outra. Isso não é um bug do harness — é a confirmação, sob uso concorrente real (mesmo que leve, 2–3 sessões), de que o servidor guarda estado de classificação global e não isola sessões por usuário.

## 2) Tempo total por sessão — fluxo completo, incluindo think-time

Da primeira chamada (`GET /`) até o fim da sessão. É a métrica mais próxima de "quanto tempo um usuário passa resolvendo uma situação", dominada pelas pausas simuladas, não pelo servidor.

**sequencial** (N=40) — min 12.71s, média 31.57s, p50 30.39s, p95 49.21s, p99 52.38s, máx 52.38s

**paralelo** (N=3) — min 15.99s, média 18.41s, p50 16.14s, p95 23.10s, p99 23.10s, máx 23.10s


## 3) Tempo de servidor por sessão — só a soma das chamadas HTTP, sem think-time

A mesma sessão, mas contando só o tempo realmente gasto em rede/servidor — mostra que o servidor é uma fração pequena do tempo total da sessão.

**sequencial** (N=40) — min 10.08ms, média 26.17ms, p50 21.58ms, p95 43.81ms, p99 93.19ms, máx 93.19ms

**paralelo** (N=3) — min 14.40ms, média 16.38ms, p50 15.29ms, p95 19.46ms, p99 19.46ms, máx 19.46ms
